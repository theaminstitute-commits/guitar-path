Guitar Path

Learn the fretboard one triad at a time: link the chord tones along the neck and find the shortest path.

  1. The glowing note is your start. The goal tells you which triad to build, and the start must stay its lowest-sounding note.
  2. Tap the next triad note, then the last one, following the arrows under the goal. Each arrow is one link: straight or diagonal, and a link can skip strings. Each tap draws a blue link.
  3. Links turn green on the shortest path and red if they're wrong. The note names only appear when you get the whole path.
