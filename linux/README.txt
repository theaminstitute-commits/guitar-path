Guitar Path for Linux (Linux Mint, Ubuntu and similar)

Quickest way to play
  Double-click guitar-path.html. It opens in Firefox and plays the same as the phone version.

Add it to the Mint menu
  1. Open a terminal in this folder (right-click in the folder > Open in Terminal).
  2. Run:  bash install.sh
  3. Open "Guitar Path" from the menu (Education or Games).
  It opens in its own window. If Chromium or Google Chrome is installed it uses that
  (no tabs or address bar); otherwise Firefox.

Remove it
  bash uninstall.sh

Notes
  - Works offline. With an internet connection it uses the game's own fonts;
    offline it falls back to the system font.
  - Settings (level, handedness, sound) are remembered by the browser.
  - Play with the mouse: click a fret on a string to link a note.
